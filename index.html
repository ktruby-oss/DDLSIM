01 / Project

A research environment built for distributed systems.

DDLSim-Lab is an open-source research project focused on understanding how distributed deep learning systems behave under realistic infrastructure constraints.

The platform is designed to support experimentation with large-scale, heterogeneous, and failure-prone environments. Researchers can investigate algorithms, scheduling policies, communication behavior, resource allocation, and fault-tolerance techniques without depending exclusively on expensive dedicated physical testbeds.

Rather than treating distributed training as an isolated machine-learning problem, DDLSim-Lab approaches it as a systems problem spanning compute, networking, orchestration, and reliability.

Systems-level experimentation

Model the interaction between distributed workloads and the infrastructure beneath them — from network conditions to compute placement and failure behavior.

workload → scheduler → network → nodes → telemetry
02 / Research areas

What the lab is designed to investigate

The environment brings several system dimensions together so experiments can examine their interactions rather than isolated variables.

Distributed Training

Explore distributed deep learning workloads across multiple compute nodes and heterogeneous environments.

Network Behavior

Study latency, jitter, packet loss, bandwidth constraints, and communication patterns affecting distributed workloads.

Scheduling

Investigate placement, scheduling, resource allocation, and adaptive strategies for distributed workloads.

Performance

Evaluate scaling behavior and system performance under changing workload and infrastructure conditions.

Fault Tolerance

Experiment with failures, degraded nodes, unreliable links, recovery strategies, and resilient system behavior.

Edge–Cloud Systems

Examine distributed workloads spanning edge devices, local resources, and cloud infrastructure.

INFRASTRUCTURE / 03

Bare-metal experimentation

Infrastructure fidelity

When the infrastructure is part of the experiment.

DDLSim-Lab is designed to support bare-metal deployments when experiments require direct access to networking, compute, and kernel-level behavior.

  • Reduced virtualization overhead for performance-sensitive measurements.
  • Direct access to network interfaces for realistic communication experiments.
  • Support for technologies such as SR-IOV and RDMA where the experimental environment requires them.
04 / Open research

Built to be inspected, reproduced, and extended.

DDLSim-Lab is developed as an open-source research project. Researchers and contributors can inspect the implementation, reproduce experiments, propose improvements, and extend the environment for new research questions.
